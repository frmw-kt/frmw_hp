- 主検索語の問いへの直接の答え：オフラインコンバージョンとは、広告から問い合わせた人がその後サイトの外で商談・契約に至った成果を、元の広告と結びつけて Google広告や Meta広告に送り返す仕組み。問い合わせ時に GCLID・メールアドレス等を顧客管理に残し、成約したら日時と一緒に取り込む。
- summary／takeaways：JSON のとおり
- FAQの候補（出どころ）：①取り込みからレポート表示までの時間（koukoku.jp「データアップロードのタイミング」、Google ヘルプ 1722022）②電話の成約も返せるか（kwm「広告経由での着電が発生するケース」、Google ヘルプ 2998031）③広告経由でない成約もアップロードするか（Google 実装チェックリスト 16782203 の項目。上位記事は扱っていない誤解しやすい点）
- 独自性の型：①判断基準＝h2「広告に返す段階は…」（期間内なら商談と成約を別々に、収まらなければ商談を返す。Meta の目安に届かなければ Google 側か台帳から）と h2「業態で変わるのは…」②チェックリスト＝h2「送る前に…」の5項目（Google・Meta・個人情報保護委員会の内容を確かめる順に並べ直したもの）と、顧客管理の列の表
- 読者・状況・解決したい疑問：問い合わせ後の商談・成約を営業や店舗で行う事業者。広告の「問い合わせ件数」と実際の成約が合わず、成約で広告を評価したい。何を準備し、どの媒体でどう設定し、個人情報で何に気を付けるか
- 記事が伝える結論：照合の手がかり（GCLID・連絡先）は問い合わせ時に残す。Google は新規ならリードの拡張コンバージョン。Meta はコンバージョンAPI（リード獲得広告は CRM 連携で「適格リード数を最大化」）。返す段階は取り込める期間と件数で決める。送る前に開示・同意・禁止情報・法的整理を確かめ、取り込み後は2〜3週間サブで確かめる
- descriptionの下書き：JSON のとおり（読者の状況「商談・成約が電話や面談で決まる事業者向け」、数値「GCLID（90日以内）」）
- 新規／リライト：新規。柱 conversion-tracking-design の h2「サイトの外で起きた成約は…」は要約（GCLID と CAPI の紹介のみ）で、実装手順・顧客管理の列・個人情報・Meta の条件は扱っていない。google-ads-conversion-setup はリードの拡張コンバージョンを1段落で紹介し、Data Manager API 等は #26 の候補として除外していた
- 各h2の1文目：
  1. オフラインコンバージョンは、広告の外で決まった成約を広告に返す仕組み｜オフラインコンバージョンは、広告のクリックや電話の後にオフラインで起きた行動（契約書への署名、店舗での購入、電話注文、予約など）を、広告の成果として媒体に記録するためのデータです。
  2. 広告に返す段階は、成約までの日数と月の件数で決める｜広告に返す段階は、クリックから成約までの日数が媒体の取り込める期間に収まるかで決め、収まらない場合は成約より手前の商談を返します。
  3. Google広告で新しく始めるなら、リードの拡張コンバージョンを選ぶ｜Google広告でオフラインコンバージョンを新しく始めるなら、GCLID だけで照合する「オフライン コンバージョンのインポート」ではなく、「リードの拡張コンバージョン」から始めることを Google は勧めています。
  4. Google広告の設定は、タグ・アクション・規約の3段階で進める｜Google広告でリードの拡張コンバージョンを設定する手順は、Google タグでフォームの入力を捉える設定、オフラインのコンバージョン アクションの作成とデータソースの接続、顧客データに関する規約への同意の3段階です。
  5. 顧客管理には、問い合わせ時のIDと連絡先、成約の日時を残す｜成約を広告に返すには、問い合わせを受けた時点で GCLID・メールアドレス・電話番号を顧客管理に残し、商談や成約に進んだら、その日時（タイムゾーンつき）と段階の名前を書き足します。
  6. Meta広告には、コンバージョンAPIで商談・成約を送る｜Meta広告にオフラインの商談・成約を返す方法は、イベントマネージャのデータセットにコンバージョンAPI（パートナー連携を含む）で送るか、手動でアップロードするかで、以前のオフラインコンバージョンAPI は2025年5月に廃止されています。
  7. 送る前に、開示・同意・送らない情報・法律上の整理を確かめる｜顧客のメールアドレスや電話番号を広告媒体に送る前に、プライバシーポリシーでの開示、法律上必要な同意、送ってはいけない情報、自社のデータに限っているか、個人情報保護法上の整理の5点を確かめます。
  8. 取り込んだ後は、2〜3週間「サブ」で確かめてから入札に使う｜Google は、リードの拡張コンバージョンで新しく作ったコンバージョン アクションを最初の2〜3週間は「サブ」にしておくことを勧めており、成約がレポートに想定どおり記録されるのを確かめてから自動入札に使います。
  9. 業態で変わるのは、返す段階と送れない情報の範囲｜業態によって、広告に返す段階と、送ってはいけない情報の範囲が変わります。
