- 各h2の1文目：
  - LPとホームページの違いは、1つの広告に合わせて作るかどうか｜Google広告の定義では、広告をクリックした人に表示されるページの URL を最終ページ URL と呼び、これを「ランディング ページ」とも呼ぶので、ホームページの中のページも広告のリンク先に指定すればランディングページになります。
  - リンク先は、広告で約束した内容が載っているページにする｜広告のリンク先は、専用LPか既存ページかにかかわらず、広告で示した商品・特典・行動がそのまま載っているページにします。
  - 遷移先は、ページの有無・特典の掲載・直せるかの順で決める｜広告の遷移先は、①…②…③…の順に確かめて決めます。
  - 月の予算が少ないほど、LPを分けると1ページの件数が減る｜月の広告費を複数のLPに均等に分けると…4ページに分けたときの問い合わせは1ページ5件になります。
  - P-MAXは初期設定で、LP以外のページにも誘導する｜Google広告のP-MAX（パフォーマンス最大化）キャンペーンでは最終ページ URL の拡張が初期設定でオンになっており…
  - Meta広告は、ウェブサイトのほかにフォームや電話も選べる｜Meta広告のリード獲得キャンペーンでは…「ウェブサイト」を選ぶ場合は事前にMetaピクセルを設定してインストールする必要があります。
  - 業態で、既存ページで足りる場合と専用LPが要る場合が変わる｜問い合わせ型ではサービスページ、予約・来店型ではメニュー・料金のページ、EC型では商品ページが既存ページの候補になり…
  - 公開前に、リンク先を5つの項目で確かめる｜広告を公開する前に、リンク先のページを…5項目で確かめます。
