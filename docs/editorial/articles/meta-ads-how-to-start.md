  2. 手順1：ビジネスポートフォリオは自社で作り、外部にはパートナーとして渡す → 「Meta広告を始める手順1では、ビジネスのFacebookページと広告アカウントを用意し、将来運用を外部に任せる可能性があるなら、ビジネスポートフォリオを自社で作って、外部の担当者にはパートナーとしてアクセスを付与する形にします。」
  3. 手順2：支払い方法は最初の広告で決まるため、先に社内で決める → 「Meta広告の支払い設定は、最初の広告を作るときに選んだ支払い方法で『自動決済』か『利用可能残高』かが決まり、どちらかに固定される場合もあるため、カード払いにするか前払いにするかを先に社内で決めてから登録します。」
  4. 手順3：配信前に成果のイベントを決め、Metaピクセルで記録する → 「Meta広告を始める手順3では、問い合わせ・予約・購入のどれを成果とするかを決め、Metaピクセル（必要ならコンバージョンAPIも）で、サイト上のその行動をイベントとして記録できるようにします。」
  5. 手順4：広告マネージャで、キャンペーン・広告セット・広告の順に作る → 「Meta広告マネージャでは、広告を『キャンペーン』『広告セット』『広告』の3つのレベルで上から順に作り、1つのキャンペーンに1つ以上の広告セットが、1つの広告セットに1つ以上の広告が入ります。」
  6. キャンペーンの目的は、手順3で決めた成果に最も近いものを選ぶ → 「Meta広告のキャンペーンの目的は、認知・トラフィック・エンゲージメント・リード・アプリの宣伝・売上の6種類で、選んだ目的によって後で選べる最適化の対象が変わるため、手順3で決めた成果に最も近い目的を選びます。」
  7. 広告セットで配信の対象・場所・予算・期間を、広告で見た目を決める → 「Meta広告の広告セットではオーディエンス…・配置…・予算…・スケジュール…を、広告では名義・フォーマット・クリエイティブを決めます。」
  8. 手順5：公開すると審査に入り、ほとんどは24時間以内に終わる → 「Meta広告は公開すると審査に入り、2026年10月10日時点のMetaのヘルプでは、ほとんどの広告は24時間以内に審査が完了するものの、さらに時間がかかることもあるとされています。」
  9. 手順6：配信が始まったら、配信列のステータスを全レベルで見る → 「配信が始まったMeta広告は、広告マネージャの［配信］列でキャンペーン・広告セット・広告それぞれのステータスを確認し、数字は［チャートを見る］で確認します。」
  10. 配信が始まらないときは、どの順で確かめるか → 「Meta広告の配信が始まらないときは、①すべてのレベルの［配信］列、②却下の通知、③審査中・処理中の経過時間、④掲載開始日、⑤支払いや広告アカウントの制限、の順に確かめます。」
  11. 問い合わせ型、予約・来店型、EC型で、最初の設定はどう変わるか → 「Meta広告の最初の設定は、問い合わせ型ならリードの目的と問い合わせフォームのあるページ、予約・来店型なら予約ページ、EC型なら売上の目的と商品ページが出発点になります。」
  12. 問い合わせや購入を増やすなら、投稿の「宣伝」より広告マネージャで作る → 「FacebookページやInstagramの投稿の『宣伝』（投稿の宣伝、いわゆるブースト）は公開済みの投稿から作れる簡単な広告の出し方ですが、広告マネージャほどカスタマイズやターゲット設定の選択肢がなく、『リード』『売上』などの目的は広告マネージャで選びます。」
