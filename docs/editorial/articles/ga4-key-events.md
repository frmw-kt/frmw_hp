- 各h2の1文目：
  1. キーイベントは以前の「コンバージョン」で、広告の入札とは別の指標｜GA4のキーイベントは「ビジネスの成果にとって特に重要なアクションを測定するイベント」で、収集したどのイベントでもキーイベントにでき、GA4のレポートで流入元ごとに数えられます。
  2. キーイベントにするのは問い合わせ・予約・購入の完了だけにする｜キーイベントには、問い合わせの送信完了・予約の完了・購入のように成果そのものを表すイベントを選び、ページの表示などの手前の行動は通常のイベントのまま残すのが、この記事の判断基準です。
  3. 完了ページがあれば、コードなしでキーイベントを作れる｜問い合わせの送信後に完了ページ（サンクスページ）が表示されるサイトでは、完了ページのURLが表示されたときの page_view をもとに新しいイベントを作り、キーイベントとしてマークすれば、サイトのコードを変えずに設定できます。
  4. 設定後はリアルタイム レポートで確かめ、標準レポートは24時間待つ｜キーイベントの設定は、自分で完了ページまで進み、リアルタイム レポートの［イベント名ごとのキーイベント数］カードにそのイベントが出るかで確かめます。
  5. 広告の入札に使うには、キーイベントからコンバージョンを作りメインにする｜GA4のキーイベントを Google広告の入札に使うには、GA4のプロパティと Google広告アカウントをリンクし、Google広告で自動タグ設定を有効にしたうえで、キーイベントをもとに Google広告のコンバージョンを作り、入札に使うものを「メイン」にします。
  6. GA4とGoogle広告の件数は、計測期間とカウント方法の違いで一致しない｜GA4のキーイベントの数と Google広告のコンバージョンの数は、計測期間の初期設定（GA4は90日、Google広告はクリック後30日）、カウント方法、数える流入元が違うため、一致しないことを前提に比べます。
